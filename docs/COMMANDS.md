# YiMao · 命令参考

> 本文按当前代码实现整理，避免把未接入的历史设想写成可用功能。

## 私聊可用命令

| 命令 | 说明 |
|---|---|
| `/start` | 打开主菜单 |
| `/search` | 进入搜索求片；也可以在私聊里直接发送片名 |
| `/ai` | 进入“今晚看什么”一次性 AI 推荐模式 |
| `/ai <需求>` | 直接按口味/心情获取 AI 推荐，例如 `/ai 想看烧脑悬疑` |
| `/requests` | 查看求片进度 |
| `/watchlist` | 查看求片进度，与 `/requests` 同源 |
| `/wish` | 查看许愿池 |
| `/wish <片名>` | 把暂时无源的影片加入许愿池 |
| `/adventure` | 开始电影冒险 |
| `/game` | 打开游戏中心 |
| `/rank` | 查看冒险排行 |
| `/mystats` | 查看个人冒险战绩 |
| `/go` | 快速开始电影冒险 |
| `/dream` | 开始本周挑战 |
| `/portrait` | 生成观影画像 |
| `/review` | 写影评 |
| `/link` | 绑定 MoviePilot 账号 |
| `/quota` | 查看配额 |
| `/help` | 帮助中心 |
| `/status` | 查看 Bot 状态 |
| `/id` | 查看当前聊天 ID / 用户 ID |

## 使用方式

### 搜索求片

私聊机器人，直接发送片名即可：

```text
星际穿越
沙丘 2024
权力的游戏
```

也可以点主菜单里的“搜索求片”。

### AI 推荐：今晚看什么

AI 推荐是独立模式，不会影响搜索求片。

- 点主菜单“今晚看什么”，下一条文字会走 AI 推荐。
- 或直接使用：

```text
/ai 想看一部轻松治愈的电影
/ai 来点烧脑悬疑，不要太长
```

推荐结束后会自动回到搜索求片模式。

### 许愿池

搜不到或暂时无源的片，可以加入许愿池：

```text
/wish 影片名
```

之后有源会私信通知，并提供“立即求片”入口。

### 求片进度

```text
/requests
/watchlist
```

用于查看审核中、下载中、已完成、失败/重试等状态。

## 群组行为

当前群组定位是：**通知与轻量引导**，不是公开搜片界面。

为了保护观影隐私，群组中不会展开搜索结果、求片进度或配额详情。群里发送这些命令时，机器人会提示去私聊使用：

```text
/start
/search
/wish
/requests
/watchlist
/quota
/ai
```

群组主要用于：

- 入库通知
- 拼车到货提醒
- 系统公告

## 注意

- 当前没有 `/daily`、`/profile`、`/leaderboard`、`/quicklink`、`/request` 等命令入口。
- 当前没有 `/s`、`/req`、`/rec` 等别名命令。
- 如果后续实现这些功能，再补充到本文档。
