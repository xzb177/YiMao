# YiMao · 命令参考

> 本文按当前代码实现整理，避免把未接入的历史设想写成可用功能。

## 私聊可用命令

| 命令 | 说明 |
|---|---|
| `/start` | 打开主菜单；合法的 Mini App deep link 会打开对应媒体 |
| `/search` | 进入搜索求片；也可以直接发送片名 |
| `/requests` | 查看求片与洗版任务进度 |
| `/watchlist` | 与 `/requests` 同源的片单/进度视图 |
| `/wish` | 查看许愿池 |
| `/wish <片名>` | 把暂时无源的影片加入许愿池 |
| `/portrait` | 生成观影画像 |
| `/link <用户名> [密码]` | 绑定或创建 MoviePilot 账号 |
| `/unlink` | 二次确认后解绑 MoviePilot 账号 |
| `/resetpw [用户名]` | 重置密码；普通用户只能重置自己的绑定账号，管理员可指定用户名 |
| `/quota` | 查看配额 |
| `/help` | 帮助中心 |
| `/status` | 查看 Bot 版本与当前身份；管理员还可查看脱敏部署诊断 |
| `/id` | 查看当前聊天 ID / 用户 ID |

## 使用方式

### 搜索求片

私聊机器人，直接发送片名即可：

```text
星际穿越
沙丘 2024
奥本海默
```

也可以点主菜单里的「搜索求片」。

### 许愿池

搜不到或暂时无源的片，可以加入许愿池：

```text
/wish 影片名
```

之后有源会私信通知，并提供「立即求片」入口。

### 求片进度

```text
/requests
/watchlist
```

用于查看审核中、下载中、已完成、失败/重试等状态。

### 观影画像

```text
/portrait
```

基于 Emby 观看记录生成统计画像；需要先绑定账号并配置 Emby。

### 账号操作

```text
/link 新用户名
/link 已有用户名 密码
/unlink
/resetpw
```

`/unlink` 必须再次确认。`/resetpw` 依赖部署端配置 MoviePilot 数据库路径；密码只发送到用户私聊，不应在群里提交凭据。

## 群组行为

当前群组定位是：**通知与轻量引导**，不是公开搜片界面。

为了保护观影隐私，群组中不会展开搜索结果、求片进度或配额详情。以下命令使用仅调用者可见的入口；发送失败时不会退化为公开展示私人数据：

```text
/start
/search
/wish
/requests
/watchlist
/quota
/portrait
```

`/id` 的群聊结果会出现在群里，内容应按公开消息处理；账号绑定、解绑、密码重置和状态命令不属于群菜单入口。

群组主要用于：

- 入库通知
- 拼车到货提醒
- 系统公告

## 注意

- 私聊命令菜单展示 `/start`、`/search`、`/requests`、`/wish`、`/link`、`/quota`、`/portrait`、`/help`；其他兼容命令可直接输入。
- 游戏中心、电影冒险、AI 电影解说、影评与相关命令（`/game`、`/narrate`、`/review`、`/adventure`、`/go`、`/rank`、`/mystats`、`/dream`、`/ai`）已整体下线，不再受理。
- 当前没有 `/daily`、`/profile`、`/leaderboard`、`/quicklink`、`/request` 等命令入口。
- 当前没有 `/s`、`/req`、`/rec` 等别名命令。
- 如果后续实现这些功能，再补充到本文档。
