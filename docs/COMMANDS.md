## 💡 使用技巧

### 搜索技巧
1. **直接搜索**: 直接输入内容名称
   - `复仇者联盟`
   - `权力的游戏`

2. **带年份搜索**: 精确匹配年份
   - `沙丘 2024`
   - `2024年的电影`

3. **使用别名**: 可以用简写
   - `/s 复仇者联盟` (等同于 `/search`)
   - `/req 沙丘` (等同于 `/request`)

### 快速操作
- 点击左下角菜单按钮快速访问所有功能
- 使用搜索结果的按钮直接请求
- 使用 `/daily` 每天签到获得额外经验

### 账号绑定
要使用请求功能，需要先绑定 Jellyseerr 账号：
```
/link 账号名 密码
```
或使用快速绑定：
```
/quicklink 账号名 密码
```
