# 文案基准（Copy Guide）

本项目所有**用户可见文案**以本文件为唯一事实来源。改动用户可见字符串前先查这里；
新增概念先在此登记，再落到代码。自动校验见 `scripts/copy-lint.py`。

---

## 1. 品牌名

| 场景 | 唯一写法 | 说明 |
|------|---------|------|
| 中文全名 | `云海求片助手` | README / 文档标题，需要完整介绍产品时 |
| 产品短名 | `云海求片` | Bot 欢迎卡主标题、Mini App 主标题与 boot 文案 |
| 中文简称 | `云海` | 短标签与口语场景：`想看的，交给云海`、`云海可看` |
| 英文代号 | `YiMao` | 仓库名、镜像名、容器名、`LOG_PREFIX`、目录名 |

禁止：`YiMao 放映室`（中英混排）、`云海影视助手`、`云海放映室`、`毅猫`、`一猫`。
中文正文里不要把 `YiMao` 当名字用——那是代号，不是称呼。

Bot 与 Mini App 的界面文案集中在 `internal/richmessage/pages_copy.go` 的 `copy*` 常量，
改文案改那里，不要在 handler 里散写。

## 2. 功能名

用户可见的功能一律用「唯一写法」列，不得出现「禁用写法」列。

| 概念 | 唯一写法 | 禁用写法 |
|------|---------|---------|
| 搜索并提交求片 | `搜索求片` | 找片、搜片、普通求片 |
| 求片处理列表 | `求片进度` | 我的进度、我的求片、我的请求、求片记录 |
| 无源片众筹 | `许愿池` | 愿望池、心愿单 |
| 观影数据画像 | `观影画像` | 灵魂画像、裸用「画像」 |
| 已有版本升级 | `洗版` | 换版、升级版本 |
| 问题上报 | `问题反馈` | 报错、意见反馈 |

命令菜单描述与页面标题必须用同一写法，例如 `/requests` 的描述、按钮文字、
页面标题三处都是 `求片进度`。

### 已下线功能（禁止复活）

游戏娱乐与 AI 能力已整体移除。以下词汇不得出现在任何用户可见文案、按钮、
回调 action 或命令菜单中：

`电影冒险`、`电影大冒险`、`闯关`、`游戏中心`、`盲盒`、`命运轮盘`、`情报站`、
`AI 解说`、`写影评`、`成就`、`段位`、`品味对比`、`情绪画像`

对应命令 `/adventure`、`/go`、`/rank`、`/mystats`、`/dream`、`/game`、
`/narrate`、`/review`、`/ai` 均已下线。守卫测试：

- `internal/callback/no_legacy_game_actions_test.go` — 回调 action 白名单
- `internal/services/no_legacy_game_surface_test.go` — 原生菜单按钮
- `internal/richmessage/no_legacy_game_copy_test.go` — Rich Message 文案
- `cmd/bot/no_legacy_game_menu_test.go` — 命令菜单注册

## 3. 求片状态标签

唯一来源：`internal/ui/ui.go` 的 `getRequestStatusLabel`。不要在别处另起一套。

| 内部状态 | 用户看到 |
|---------|---------|
| pending / wish / reviewing | `待审核` |
| searching / recycled / stuck | `正在找资源` |
| downloading | `下载中` |
| completed | `已入库` |
| failed / error | `处理失败` |
| cancelled | `已取消` |

`MoviePilot 下载完成` 与 `Emby 已可看` 是两个状态，不能混用同一句文案。

## 4. 错误与重试话术

按「用户下一步该做什么」选，不要按心情写。

| 情况 | 唯一写法 |
|------|---------|
| 瞬时失败，原地重试即可 | `……失败，请稍后再试` |
| 上下文已失效，需返回重来 | `……请返回后重试` |
| 详情页会话过期 | `……请重新打开详情页` |
| 缺前置条件 | 先说缺什么，再给按钮，例如 `求片需要先绑定账号` |

禁用：`请稍后重试`、`请重试`、`再试一次`、`这次操作没有成功`、`下次一定赢`。
统一收敛到 `请稍后再试`——一种说法就够，四种只会显得代码是拼的。

不要把内部错误直接抛给用户（`CallbackMsg: err.Error()`）。

## 5. 按钮词表

Rich Message 按钮使用四字词表，见 `pkg/types/button_style.go` 与
`internal/richmessage/button_grid_test.go`：

```text
搜索求片  查看进度  帮助说明  更多功能  返回首页  刷新状态  申请洗版
进入许愿  系统设置  问题反馈  观影画像  通知设置  绑定账号  重置密码
我的反馈  观影周报  求片热度  管理后台  取消操作
```

只有 `搜索求片` 用 success 绿色，其余为 primary。新增按钮先进这张表。

## 6. 标点与排版

- 引用界面元素、功能名：用直角引号 `「求片进度」`，不用 `“求片进度”`
- 作品名：用书名号 `《银翼杀手》`
- 中文句内不用半角 `,` `?` `!`；用 `，` `？` `！`
- 一句话的短提示不加句号；多句成段时才加
- 冒号统一全角 `：`（`状态：已入库`）
- Emoji 只在行首做标识，一行最多一个，不在句中穿插

---

## 7. 语气

- 说人话，不喊口号。描述事实与下一步，不做情绪施压。
- 不用赌博、死亡、羞辱类比喻（`豪赌`、`死神`、`碾压`、`无人能及`）。
- 不承诺不确定的结果。`正在找资源` 是事实，`马上就好` 不是。
- 面向新用户的提示要给出具体动作，而不是「请检查配置」。

---

## 8. 自动校验

```bash
python3 scripts/copy-lint.py            # 全仓文案检查
python3 scripts/copy-lint.py --stats    # 附带术语分布统计
```

检查项：品牌混排、禁用功能名、已下线功能词、禁用重试话术、中文里的半角标点、
弯引号。新增禁用词加到脚本顶部的 `RULES` 表并同步本文件。
