# Contributing

感谢你对 YiMao 的关注。

## 提交建议

- 提交前请先阅读 `README.md`、`ARCHITECTURE.md` 与 `COMMANDS.md`。
- 功能改动尽量保持“低侵入、可回滚”。
- 文案/UI 改动请保持语义一致、避免重复表达。

## 开发流程

1. Fork 并新建分支（`feat/*`、`fix/*`、`docs/*`）。
2. 提交小步可读的 commit。
3. 提交 PR，说明：背景、改动点、影响范围、回滚方式。

## 代码风格

- Go 代码保持简单可读，避免过度抽象。
- 业务逻辑与文案尽量分层。
- 不提交敏感信息（Token、Key、密码、隐私数据）。

## 文档贡献

欢迎补充：
- 部署与运维案例
- 常见问题排障
- UI/交互建议与截图对比
