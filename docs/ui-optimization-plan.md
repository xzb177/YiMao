# YiMao UI 优化方案

## 📋 当前问题分析

### 搜索结果页面
**位置**: `internal/handlers/search.go` -> `sendSearchResults()`

**当前实现**:
```go
text := fmt.Sprintf("🔍 搜索结果「%s」\n\n找到 %d 条结果\n\n",
    query, len(results.Results))
```

**问题**:
- ❌ 缺少视觉分隔线
- ❌ 格式单调，无风格化
- ❌ 信息展示不完整（缺少热度、年份等）
- ❌ 与整体UI风格不一致

### 媒体详情页面
**位置**: `internal/handlers/callback.go` -> `buildDetailFromMediaInfo()`

**当前实现**:
```go
msg.Bold(fmt.Sprintf("%s %s", typeIcon, info.Title)).Newline()
msg.Newline()
msg.Textf("📅 %d年  ", info.Year.Int())
msg.Textf("⭐ %.1f分  ", info.Rating)
msg.Textf("🏷️ %s", typeLabel).Newline()
```

**问题**:
- ❌ 缺少暗黑霓虹风格装饰
- ❌ 信息展示不够清晰
- ❌ 缺少视觉层次感

---

## 🎨 优化目标

### 1. 统一视觉风格
所有页面使用**暗黑霓虹风**（StyleNeon）

### 2. 增强视觉层次
- 使用分隔线区分不同区块
- 使用特殊字符装饰关键信息
- 使用emoji增强视觉识别

### 3. 提升信息密度
在有限空间内展示更多信息：
- 搜索结果：标题 + 年份 + 评分 + 类型 + 热度
- 详情页：完整元信息 + 剧情简介 + 相关信息
