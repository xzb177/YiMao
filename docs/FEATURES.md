# 云海求片助手功能说明

> 本页只描述当前仍在维护的产品能力。命令、配置和部署步骤分别以 [COMMANDS.md](COMMANDS.md)、[`.env.example`](../.env.example) 与 [DEPLOY.md](DEPLOY.md) 为准。

## 核心求片流程

1. 从主菜单进入「搜索求片」，或直接发送影片名称。
2. 在 TMDB 搜索结果中选择电影或剧集。
3. 查看详情、季度信息与候选片源。
4. 提交求片，并在「求片进度」中查看、撤回或重新分享。

普通求片始终是默认路径；游戏中心和 Mini App 监控视图是辅助能力，不影响搜索与订阅流程。

## 当前能力

### 搜索与求片

- 电影、剧集搜索与分页
- 剧集季度选择
- MoviePilot 求片提交与候选资源查看
- 用户配额、求片审核与状态跟踪
- 搜索历史、热门搜索与趋势
- 暂无片源时加入许愿池，后续自动重搜并通知

### 个人体验

- 求片进度与片单
- 观影画像
- 问题反馈、追问与满意度评价
- 入库通知与每周报告

### 影视发现工具

- AI 电影解说
- 电影盲盒与命运轮盘
- 观影画像

### 管理与运维

- 管理员审核、反馈处理与通知设置
- `/health` 与 `/api/health` 健康检查
- Mini App 安全监控视图：可用空间、队列摘要和链路健康
- API Key 鉴权、限流与 IP 防护
- Docker Compose 部署、数据备份与部署前验收

## 常用入口

| 入口 | 用途 |
|------|------|
| `/start` | 主菜单 |
| `/search` | 搜索求片 |
| `/requests` | 求片进度 |
| `/watchlist` | 片单与进度 |
| `/portrait` | 观影画像 |
| `/game` | 游戏中心 |
| `/help` | 帮助 |

完整、可执行的命令清单见 [COMMANDS.md](COMMANDS.md)。
