# 云海求片助手功能说明

> 本页只描述当前仍在维护的产品能力。命令、配置和部署步骤分别以 [COMMANDS.md](COMMANDS.md)、[`.env.example`](../.env.example) 与 [DEPLOY.md](DEPLOY.md) 为准。

## 核心求片流程

1. 从主菜单进入「搜索求片」，或直接发送影片名称。
2. 在 TMDB 搜索结果中选择电影或剧集。
3. 查看详情、季度信息与候选片源。
4. 提交求片，并在「求片进度」中查看、撤回或重新分享。

搜索求片始终是 Bot 默认路径；Mini App 则直接进入任务首页。许愿池、洗版和观影画像是辅助能力，不影响搜索与订阅流程。

## 当前能力

### 搜索与求片

- 电影、剧集搜索与分页
- 剧集季度选择
- MoviePilot 求片提交与候选资源查看
- 用户配额、求片审核与状态跟踪
- 搜索历史、热门搜索与趋势
- 暂无片源时加入许愿池，后续自动重搜并通知

### 个人体验

- 求片进度与片单
- 想看/拼车、洗版申请与任务撤回
- 观影画像
- 问题反馈、追问与满意度评价
- 入库通知与每周报告

### Mini App 任务中心

- App-first 首页展示可看内容、阻塞事项和正在处理的任务
- 搜索、详情、季度、求片/洗版提交、任务进度、分页、撤回、想看、许愿和问题反馈
- 请求链使用 `mode: 'request'`，分页、取消和并发响应都有状态保护；失败后可以在当前上下文恢复
- 原生 Dialog、安全区适配和移动端三列底栏：首页、找片、任务

### 管理与运维

- 管理员审核、反馈处理与通知设置
- 洗版批准后先打开短 callback 的明确完成确认；查看详情不会改变工单状态
- 管理员可认领、释放和重试洗版核验；只有旧版仍保留且 Emby 出现不同的新 MediaSource 才能完成
- 未被认领的已批准洗版可由 Emby 入库事件按同一安全条件自动完成
- `/health` 与 `/api/health` 健康检查

- API Key 鉴权、限流与 IP 防护
- Docker Compose 部署、数据备份与部署前验收

## 常用入口

| 入口 | 用途 |
|------|------|
| `/start` | 主菜单 |
| `/search` | 搜索求片 |
| `/requests` | 求片进度 |
| `/watchlist` | 片单与进度 |
| `/wish` | 许愿池 |
| `/portrait` | 观影画像 |
| `/link`、`/unlink` | 绑定或解绑 MoviePilot 账号 |
| `/resetpw` | 重置已绑定账号密码 |
| `/status`、`/id` | Bot 状态与当前会话 ID |
| `/help` | 帮助 |

完整、可执行的命令清单见 [COMMANDS.md](COMMANDS.md)。

## 部署

部署、备份、升级和回滚统一见 [DEPLOY.md](DEPLOY.md)，不要复制 SQLite 主文件或绕过 `manage.sh` 直接替换生产容器。


- 洗版范围：电影仅整片；剧集仅允许指定的一季一集，禁止整剧、整季与多集洗版。
