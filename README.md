# 云海看板娘 - Emby Telegram Bot

> 一款功能强大、用户友好的 Jellyfin/Emby 媒体库 Telegram 机器人，支持智能求片、实时通知、用户管理等丰富功能。

[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

## ✨ 核心亮点

### 🎯 智能求片系统
- **一键请求** - 搜索媒体后点击按钮即可发起求片请求
- **智能搜索** - 支持中英文搜索，自动识别电影/剧集类型
- **配额管理** - 每日请求配额限制，防止滥用，支持配额自动重置
- **状态跟踪** - 自动跟踪请求状态，完成后通知用户
- **防重复** - 媒体已存在时友好提示，避免重复请求

### 📱 优秀用户体验
- **友好文案** - 精心设计的引导文案，步骤清晰，新手友好
- **消息编辑** - 优先编辑原消息而非发送新消息，减少聊天刷屏
- **内联按钮** - 丰富的快捷操作按钮，无需输入复杂命令
- **分页浏览** - 搜索结果分页显示，每页8条，翻页便捷
- **智能提示** - 根据用户状态提供个性化提示（配额、绑定状态等）

### 🔔 实时通知系统
- **入库通知** - 新内容入库时自动发送美观的通知消息
- **请求状态** - 求片请求批准/拒绝/可用时自动通知
- **问题反馈** - 问题报告创建/评论/解决时实时通知管理员
- **每日汇总** - 每天23:59自动发送当日统计报告

### 👥 用户管理
- **账号绑定** - 支持通过用户名密码绑定 Jellyfin 账号
- **权限控制** - 管理员审核机制，确保安全性
- **配额系统** - 电影/剧集独立配额，灵活管理
- **用户统计** - 活跃度排行、热门媒体、请求趋势

### 🛠️ 管理员功能
- **待处理请求** - `/pending` 查看所有待处理的求片请求
- **快速操作** - 一键批准/拒绝请求，支持批量处理
- **问题管理** - 查看和处理用户报告的问题
- **用户管理** - 查看用户列表、手动绑定账号
- **统计数据** - `/stats` 查看详细的服务统计数据

## 🏗️ 技术架构

### 模块化设计
采用参考 MoviePilot 的模块化架构，代码清晰易维护：

```
bot/           # 消息处理模块
├── handler.go     # 统一消息处理入口
├── editor.go      # 消息编辑和发送
├── integration.go # 模块集成
├── quota.go       # 配额管理
└── feedback.go    # 反馈管理

session/       # 会话管理
└── manager.go     # 用户会话状态管理

callback/      # 回调处理
└── parser.go     # 回调数据解析

chain/         # 业务链处理
├── base.go        # 链基类
├── search.go      # 搜索链
├── subscribe.go   # 订阅链
└── download.go    # 下载链
```

### 核心特性
- **会话管理** - 30分钟超时，自动清理过期会话
- **消息编辑** - 优先编辑原消息，支持长消息自动拆分
- **统一回调** - `action:key:value` 格式的统一回调系统
- **链式处理** - 独立的搜索/订阅/下载链，易于扩展

## 🚀 快速开始

### 环境要求
- Go 1.21+
- Jellyfin/Emby 媒体库
- Jellyseerr 请求系统
- Telegram Bot Token

### 安装步骤

1. **克隆仓库**
```bash
git clone https://github.com/xzb177/YiMao.git
cd YiMao
```

2. **配置环境变量**
```bash
cp .env.example .env
nano .env
```

编辑 `.env` 文件：
```env
TELEGRAM_BOT_TOKEN=你的bot_token
TELEGRAM_CHAT_ID=你的群组id
PORT=8080
JELLYSEERR_URL=https://your-jellyseerr-url
JELLYSEERR_API_KEY=你的api_key
ADMINS=管理员id:姓名
```

3. **编译运行**
```bash
go build -o emby-telegram-bot
./emby-telegram-bot
```

### Docker 部署

```bash
docker-compose up -d
```
